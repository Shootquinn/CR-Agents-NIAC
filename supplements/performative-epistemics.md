# Performative Epistemics

Writing that narrates its own rigor instead of being rigorous. Each instance adds the look of self-checking and no information. Test: delete the sentence. If only word count goes, it was decorative and stays deleted. If a false or unsupported claim is left standing, it was load-bearing and stays. A number followed by the real problem with that number is epistemics; a number followed by credit for admitting the problem is the performance.

## Patterns, each cut entirely

1. **Self-narrating honesty.** A sentence whose only content is that the writer is being honest, careful, or candid. "The consequences are real and we state them plainly."
2. **Restated conclusions.** A finding given once, then delivered again as a separate insight. "The margin falls from 20 to 1.9, which is to say it has nearly vanished."
3. **Throat-clearing headers.** A header that tells the reader how to feel about the section. "Why we keep the value anyway, and it is a sourced position, though narrower than before."
4. **Meta-commentary.** Staging the argument for the reader. "Push first on the duty cycle." "It is worth noting that."
5. **Table sandwiching.** A sentence announcing what a table shows, the table, then a sentence praising what it showed. A table stands alone.
6. **Changelog leakage.** Reference to an earlier draft's numbers or claims, as if draft history were part of the claim. State the current value.
7. **Procedural statements about the writer's own work.** What was preserved, retained, avoided, ensured, or verified independently. State the result; the reader assumes the work was done.

Negative parallelism ("not only X but Y", "X rather than Y" when nobody proposed Y) is a related tic with its own entry in the AI-writing list the Editor uses.
