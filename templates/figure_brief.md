# Figure brief

One block per figure. Plan 3 to 7 figures. Exactly one has the role mission context. Every figure is cited in the text.

## Figure ID: F__

1. Claim served: one sentence from the outline. "This figure shows that ___."
2. Role: mission context, mechanism, or feasibility evidence (pick one).
3. Drawn by code: yes or no.
4. Caption: "Figure N: ..." 1 to 3 sentences, 6 to 45 words. Sentence 1 names what is shown. Add the physical size. Add the color key if color carries meaning. Add the source in (Author, Year) form if reproduced or adapted.
5. Image prompt: only when code cannot draw it. One laconic line. Write "none" when drawn by code.
6. Cited in text at paragraph n: ____

Defect rules:
1. Exactly one figure has the role mission context.
2. Every figure has a value in line 6.
3. A figure with Drawn by code: no has an Image prompt line.
