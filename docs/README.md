# docs

Reference files. The current NASA solicitation governs over all of them.

| File | What it is |
|---|---|
| `NIAC_2027_A1_solicitation.md` | Markdown copy of the 2027 A1 Phase I solicitation (Amendment 1). Run intake on the current cycle's documents; this copy is for reference. |
| `NIAC_2027_A1_FAQ.md` | Markdown copy of the 2027 A1 FAQ (2026-10-15, v2). Repo cites of "FAQ Qn" point here. |
| `SpaceTech_REDDI_2026_NRA.md` | Markdown copy of the parent SpaceTech REDDI 2026 NRA (NNH26ZTR001N). The NIAC solicitation is an appendix to it; repo cites of "NRA p.N" point here (PDF pages). |
| `2027_Overview_Chart_Template.docx` | The 2027 overview chart template. `scripts/build_overview_chart.py` fills it. |
| `CLOVER_Example_Proposal.txt` | Text of a Step A proposal by the repo author. Structure calibration only. |
| `ACTION_Example_Proposal.txt` | Text of a Step A proposal by the repo author. Structure calibration only. |
| `TitanAir_Example_Proposal.txt` | Text of a Step A proposal by the repo author. Structure calibration only. |

Do not copy text from the examples into a proposal. NIAC reviewers read for your idea, and the solicitation bars reference to other proposals.
