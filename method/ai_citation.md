## AI citation
1. NASA requires AI use cited with program, version, date and time, and how it was used (NRA p.11-12; FAQ Q45, p.9).
2. The log file is templates/ai_log.md. Copy it to cr_scratch/ai_log.md at the first session.
3. Add one row per spawn and one row per orchestrator session.
4. Fill date-time only from the pasted date command output. Agents write none (R-g).
5. Fill the version column from the answer to intake question 5.
6. Fill model with the value passed to the Agent tool model parameter, role with the Field 3 persona name, step with {N}.
7. The Manager close reads cr_scratch/ai_log.md and writes a one-paragraph citation entry: each distinct model and version, the date-time range of its rows, and the roles it served.
8. Image tools: the user logs tool, version, date and time, and the prompt file name. Add one row per image.
9. Place the entry in the references or AI-use statement, as the solicitation requires. Copy no log value from memory.
